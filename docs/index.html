    前端知识点总结

    任何不能够给你快乐的编程都是耍流氓

    Let`s Go →

    # 起步就像数 1, 2, 3 一样容易

    # 安装
yarn global add vuepress # 或 npm install -g vuepress

# 创建一个 markdown 文件
echo '# Hello VuePress' > README.md

# 开始编写
vuepress dev

# 构建为静态文件
vuepress build

    兼容性注意事项

    • VuePress 要求 Node.js >= 8
    • 知识点总结需要持之以恒的积累
    • 立目标，定计划，不断总结，持续超越
